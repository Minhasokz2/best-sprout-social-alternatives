# Contributing

Thanks for helping improve **Best Sprout Social Alternatives**! This list is only useful if it stays accurate, so every contribution is appreciated.

## What belongs on this list

A tool can be added if it:

- Is a **genuine alternative to Sprout Social** — it helps with social media scheduling, publishing, engagement, analytics or listening.
- Is **actively maintained** and publicly available.
- Has a **working website** (and a public repository, for open-source entries).
- Is **not already listed** in the same category.

## How to add or update a tool

1. Fork this repository.
2. Edit `README.md` and add the tool to the **most relevant category**.
3. Use the existing table format:

   ```markdown
   | [Tool Name](https://example.com) | Best For | One short, factual sentence about what makes it stand out. |
   ```

4. Keep descriptions **neutral and under ~15 words**. No marketing superlatives ("#1", "best ever"), and no pricing that will go out of date.
5. Place new entries at the **bottom of the table** in their category.
6. Open a pull request with a short explanation of why the tool belongs here.

## Other contributions

- **Broken or redirected links** — please fix them.
- **Outdated info** — if a tool has shut down, been acquired or rebranded, update or remove it.
- **Typos and formatting** — always welcome.

## Pull request checklist

- [ ] The tool fits the criteria above.
- [ ] The link works and points to the official website.
- [ ] The entry follows the table format.
- [ ] One tool per pull request (bulk fixes to links/typos are fine together).
